# 🎓 IlmHub — Zamonaviy Online Ta'lim Platformasi

**IlmHub** — bu O'zbekistondagi zamonaviy kasblar, dasturlash, sun'iy intellekt, dizayn va xorijiy tillarni o'rganishga mo'ljallangan to'liq interaktiv LMS (Learning Management System) platformasi.

---

## 🌟 Asosiy Imkoniyatlar

1. **Bosh Sahifa (Landing Page)**:
   - Ta'sirli Hero sarlavha va qidiruv paneli
   - Yo'nalishlar (Dasturlash, Dizayn, Sun'iy Intellekt, Tillar, Biznes)
   - Ommabop va tavsiya etilgan kurslar kartochkalari
   - Platforma afzalliklari va statistika (+12,500 talabalar, 98% natija)

2. **Kurslar Katalogi (`/courses`)**:
   - To'liq filtrlash tizimi (Kategoriya, Daraja, Bepul/Pullik)
   - Real-vaqt qidiruvi va saralash (Reyting, O'quvchilar soni, Narx)

3. **Kurs Tafsilotlari Sahifasi (`/courses/[id]`)**:
   - Kurs mundarijasi (Modullar va darslar davomiyligi)
   - O'qituvchi ma'lumotlari va talabalar fikrlari
   - Bir bosishda yozilish (Enroll) va do'stlarga ulashish

4. **Interaktiv Dars Xonasi (`/learn/[courseId]`)**:
   - Video pleyer (Darslarni tomosha qilish)
   - Darsni "Tugatildi" deb belgilash va progress foizini avtomatik oshirish
   - Oldingi / Keyingi dars navigatsiyasi
   - Konspektlar, dars kodlari va resurslar
   - Savol-javoblar (Q&A) bo'limi
   - Kurs 100% bo'lganda ochiluvchi **Rasmiy Sertifikat** modali

5. **Talaba Shaxsiy Kabineti (`/dashboard`)**:
   - Yozilgan kurslar va umumiy o'zlashtirish foizi
   - So'nggi darsni davom ettirish tugmasi
   - Olingan sertifikatlar va erishilgan yutuqlar

6. **O'qituvchi Boshqaruv Paneli (`/instructor`)**:
   - Talabalar soni, kurslar soni va umumiy tushum tahlili
   - **"Yangi Kurs Yaratish"** interaktiv formasi (nomi, narxi, modullari bilan)
   - Mavjud kurslarni boshqarish

7. **Tezkor Demo Rollar**:
   - Yuqori paneldagi (Navbar) **"Talaba"** va **"O'qituvchi"** tugmalari orqali xohlagan rolda sinab ko'rish imkoniyati.

---

## 🚀 Ishga Tushirish

1. Ushbu papkadagi **`Ishga_Tushirish.bat`** faylini ikki marta bosing.
   Yoki terminalda:
   ```bash
   npm run dev
   ```
2. Brauzeringizda **`http://localhost:3000`** manzilini oching.
